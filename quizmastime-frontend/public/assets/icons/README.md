# Advent Calendar Icons

Dieser Ordner enthält die Icons für die 24 Türchen des Adventskalenders.

## Benötigte Dateien

Erstelle 24 PNG-Dateien mit folgenden Namen:

- `day-1.png` - Icon für Tag 1
- `day-2.png` - Icon für Tag 2
- `day-3.png` - Icon für Tag 3
- ...
- `day-24.png` - Icon für Tag 24

## Spezifikationen

- **Format:** PNG mit transparentem Hintergrund
- **Empfohlene Größe:** 400x400px bis 800x800px
- **Stil:** Weihnachtlich/Winterthema passend für Kinder (6-12 Jahre)
- **Farben:** Bunt und freundlich
- **Transparenz:** Ja, transparenter Hintergrund empfohlen

## Icon-Vorschläge nach Tagen

Beispielhafte Themen für die Icons:

- Tag 1-6: Weihnachtliche Symbole (Stern, Glocke, Kerze, Schneeflocke, Tannenbaum, etc.)
- Tag 7-12: Winter-Tiere (Rentier, Schneehase, Eule, Eichhörnchen, etc.)
- Tag 13-18: Weihnachtsleckereien (Lebkuchen, Zuckerstange, Plätzchen, Kakao, etc.)
- Tag 19-23: Geschenke, Schlitten, Schneemann, Engel, etc.
- Tag 24: Besonderes Geschenk-Icon oder Weihnachtsmann

## Technische Details

Die Icons werden automatisch geladen mit dem Pfad: `/assets/icons/day-{TagNummer}.png`

### Icon-Darstellung im Kalender

- **Normale Icons:** Werden farbig mit leichtem Schatten angezeigt
- **Gesperrte Tage:** Icons werden grau und halbtransparent (Grayscale-Filter)
- **Status-Icons:**
  - Schloss-Icon (oben rechts) für gesperrte Tage
  - Häkchen-Icon (unten rechts) für abgeschlossene Tage

## Platzhalter

Wenn ein Icon fehlt, wird das Browser-Standard-Verhalten für fehlende Bilder angezeigt (broken image icon).
